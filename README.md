# ClipHub

A personal clipboard manager for macOS.

Keeps a searchable history of what you copy and lets you paste any earlier item
with a keyboard shortcut. Runs in the menu bar, stores everything locally, and
makes no network connections.

## Build

1. Open `Maccy.xcodeproj` in Xcode.
2. In **Signing & Capabilities**, enable **Automatically manage signing** and
   select your team.
3. Build & Run (⌘R).
